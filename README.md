# Typing Pet for macOS

키보드를 칠 때마다 반응하는 데스크톱 펫입니다. [swoonqx/TypingPet](https://github.com/swoonqx/TypingPet)(Windows)을 macOS용으로 다시 만들었습니다.

**[최신 버전 다운로드](../../releases/latest/download/TypingPetMac.zip)** · [변경 내역](CHANGELOG.md)

macOS 27 이상, Apple Silicon

## 설치

1. `TypingPetMac.zip`을 받아 압축을 풉니다.
2. `TypingPetMac.app`을 **응용 프로그램** 폴더로 옮긴 뒤 실행합니다.
3. **시스템 설정 → 개인정보 보호 및 보안 → 입력 모니터링**에서 `TypingPetMac`을 켭니다.

처음 열 때 실행이 막히면 **시스템 설정 → 개인정보 보호 및 보안**에서 **그래도 열기**를 누르세요. Apple 공증을 받지 않은 앱이라 처음 한 번 나타나는 경고입니다.

응용 프로그램 폴더 밖에서 실행하면 앱 안에서 업데이트할 수 없습니다.

## 사용법

- 키를 누르면 왼손·오른손 이미지가 번갈아 나오고, 흔들림 설정에 따라 펫이 튑니다.
- 펫을 드래그해서 옮길 수 있습니다.
- 메뉴 막대의 발바닥 아이콘이나 펫을 우클릭하면 설정, 크기, 항상 위에 고정, 위치 잠금, 위치 초기화, 종료 메뉴가 나옵니다.

설정 창 위쪽의 아이콘 탭으로 페이지를 고릅니다.

| 탭 | 내용 |
|---|---|
| 일반 | 크기, 흔들림, 항상 위에 고정, 위치 잠금, Dock 표시, 로그인 시 자동 실행, 언어 |
| 캐릭터 | 기본·왼손·오른손 이미지, 패턴 |
| 프리셋 | 이미지와 패턴을 슬롯 3개에 저장, 적용, 추가 펫 띄우기 |
| 정보 | 현재 버전, 업데이트 확인 |

**이미지** — PNG, JPG, GIF, APNG를 쓸 수 있습니다(15 MB, 300프레임 이하). 권장 크기는 800 × 500 px이고, 세 이미지를 같은 캔버스 크기로 만들면 가장 자연스럽습니다.

**패턴** — 특정 키나 키 조합(⌘ ⌥ ⌃ ⇧ 포함)을 누를 때만 나오는 이미지를 3개까지 등록할 수 있습니다. 캐릭터 탭에서 **+ 패턴 추가 → 트리거 기록**을 누른 뒤 원하는 키를 누르세요.

**멀티 펫** — 프리셋의 **펫 띄우기**로 기본 펫을 포함해 최대 3마리를 띄울 수 있습니다. 크기, 흔들림, 항상 위에 고정, 위치 잠금은 기본 펫 설정을 따릅니다.

**전체화면 게임** — 항상 위에 고정을 켜 두면 전체화면 게임 위에도 펫이 보입니다.

## 업데이트

하루에 한 번 새 버전을 확인하고, 새 버전이 있으면 **지금 업데이트**로 바로 설치할 수 있습니다. 설정과 입력 모니터링 권한은 그대로 유지됩니다. 메뉴 막대의 **업데이트 확인…**이나 설정의 정보 탭에서 직접 확인할 수도 있습니다.

## 개인정보

- 키가 눌렸다는 사실만 사용하며, 입력한 글자는 저장하거나 보내지 않습니다.
- 인터넷 접속은 이 저장소의 릴리즈에서 새 버전을 확인하고 받을 때뿐입니다. 자동 확인은 설정에서 끌 수 있습니다.
- 설정과 고른 이미지는 `~/Library/Application Support/TypingPetMac`에 저장됩니다.
