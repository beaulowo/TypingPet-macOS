# 🐾 Typing Pet for macOS

**키보드를 칠 때마다 캐릭터가 손을 번갈아 들며 통통 튀는 macOS용 데스크톱 펫입니다.**

[swoonqx/TypingPet](https://github.com/swoonqx/TypingPet) Windows v4.0의 기능을 macOS 27에 맞춰 Swift/AppKit으로 다시 만든 버전입니다.
원하는 이미지를 사용해 나만의 캐릭터를 만들 수 있으며,
GIF / APNG 애니메이션, 키 패턴, 프리셋, 멀티 펫 기능을 지원합니다.

> **Latest Version: v4.2** · macOS 27 · Apple Silicon

[📥 최신 버전 다운로드](../../releases/latest/download/TypingPetMac.zip) · [📝 업데이트 내역](CHANGELOG.md)

---

## ✨ 주요 기능

- ⌨️ 키보드 입력에 맞춰 캐릭터가 움직입니다.
- 🖼️ 원하는 이미지로 캐릭터를 변경할 수 있습니다.
- 🎞️ **PNG / JPG / GIF / APNG**를 지원합니다.
- 🎯 특정 키나 키 조합에 반응하는 **패턴 기능**을 지원합니다.
- 💾 최대 3개의 **프리셋**을 저장할 수 있습니다.
- 🐾 기본 펫 포함 **최대 3마리의 멀티 펫**을 동시에 띄울 수 있습니다.
- 🌐 **한국어 / English / 日本語 / 简体中文**을 지원합니다.
- 🔒 입력한 키의 내용은 저장하거나 전송하지 않습니다.
- 🔄 새 버전이 나오면 앱 안에서 바로 업데이트할 수 있습니다.

# 📥 다운로드

Typing Pet for macOS는 **GitHub Releases**를 통해 배포합니다.

➡️ **[최신 버전 다운로드 (TypingPetMac.zip)](../../releases/latest/download/TypingPetMac.zip)**

위 링크는 항상 최신 버전을 받습니다. 버전별 변경 내용은 [Releases](../../releases) 페이지에서 볼 수 있습니다.

1. `TypingPetMac.zip`을 받아 압축을 풉니다.
2. `TypingPetMac.app`을 **응용 프로그램** 폴더로 옮깁니다.
3. 응용 프로그램 폴더에서 실행합니다.

> [!NOTE]
> 응용 프로그램 폴더로 옮기지 않고 다운로드 폴더에서 바로 실행하면 앱 안에서 업데이트할 수 없습니다.

### 요구 사항

- macOS 27 이상
- Apple Silicon Mac

# 🚀 실행

`TypingPetMac.app`을 실행하면 화면 오른쪽 아래에 캐릭터가 나타나고 메뉴 막대에 발바닥 아이콘이 생깁니다.

처음 실행하면 설정 창이 한 번 자동으로 열립니다.

## 처음 열 때 "열 수 없음" 경고가 나오는 경우

이 앱은 Apple 공증을 받지 않았기 때문에, 인터넷에서 받은 앱을 처음 열 때 macOS가 실행을 막을 수 있습니다.

1. `TypingPetMac.app`을 한 번 실행합니다. 경고가 나오면 **완료**를 누릅니다.
2. **시스템 설정 → 개인정보 보호 및 보안**으로 이동합니다.
3. 아래쪽의 `"TypingPetMac"이(가) 차단되었습니다` 옆 **그래도 열기**를 누릅니다.
4. 다시 나오는 확인 창에서 **열기**를 누릅니다.

한 번 허용하면 다음부터는 바로 실행됩니다.

## 입력 모니터링 권한

다른 앱에서 타이핑할 때도 펫이 반응하려면 **입력 모니터링** 권한이 필요합니다.

1. 처음 실행하면 권한 요청 창이 나타납니다.
2. **시스템 설정 → 개인정보 보호 및 보안 → 입력 모니터링**에서 `TypingPetMac`을 켭니다.
3. 몇 초 안에 펫이 키 입력에 반응하기 시작합니다.

권한이 없으면 설정 창 맨 위에 **권한 요청** 버튼이 나타납니다. 누르면 입력 모니터링 설정 화면이 열립니다.

> [!NOTE]
> 입력 모니터링 목록에 `TypingPetMac`이 켜져 있는데도 반응하지 않으면, 목록에서 `TypingPetMac`을 **−** 버튼으로 지운 뒤 앱을 다시 실행해 권한을 새로 허용해 주세요.

# 🖱️ 기본 사용법

캐릭터를 마우스로 드래그하면 원하는 위치로 이동할 수 있습니다.

**메뉴 막대의 발바닥 아이콘을 클릭하거나 데스크톱 펫을 우클릭**하면 다음 메뉴를 사용할 수 있습니다.

| 메뉴 | 기능 |
|---|---|
| **설정…** | 설정 창을 엽니다. |
| **크기** | 작게 / 보통 / 크게 / 아주 크게 |
| **항상 위에 고정** | 다른 창보다 항상 위에 표시합니다. |
| **위치 잠금** | 마우스 입력이 캐릭터를 통과하며 드래그 이동을 막습니다. |
| **위치 초기화** | 캐릭터를 화면 오른쪽 아래로 되돌립니다. |
| **업데이트 확인…** | 새 버전이 있는지 확인합니다. (메뉴 막대 아이콘 메뉴) |
| **종료** | Typing Pet을 종료합니다. |

추가 펫을 우클릭하면 **종료** 대신 **이 펫 숨기기**가 표시됩니다.

# ⚙️ 설정

설정 창 왼쪽 사이드바에서 다음 페이지를 고를 수 있습니다.

- **일반** — 크기, 흔들림, 항상 위에 고정, 위치 잠금, Dock, 자동 실행, 언어
- **캐릭터** — 기본 / 왼손 / 오른손 이미지와 패턴
- **프리셋** — 프리셋 저장, 적용, 멀티 펫
- **업데이트** — 현재 버전, 업데이트 확인
- **설명서** — 주요 사용법

설정 창은 마지막으로 보던 페이지로 열립니다.

## ⚙️ 일반

### 크기

캐릭터의 표시 크기를 설정합니다.

- 작게
- 보통
- 크게
- 아주 크게

### 항상 위에 고정

켜면 캐릭터가 다른 창보다 항상 위에 표시됩니다.

끄면 일반적인 창처럼 다른 앱 뒤로 이동할 수 있습니다.

### 위치 잠금

켜면 마우스 클릭이 캐릭터를 통과하며 캐릭터를 드래그해서 이동할 수 없게 됩니다.

### 기본 위치로 이동

캐릭터를 화면 오른쪽 아래의 기본 위치로 되돌립니다.

---

## 💫 흔들림

타이핑할 때 캐릭터가 튀어 오르는 정도를 설정합니다. Windows 버전과 같은 방식으로, 위로 튀었다가 살짝 흔들리며 제자리로 돌아옵니다.

| 설정 | 동작 |
|---|---|
| **없음** | 위치는 움직이지 않고 이미지만 바뀝니다. |
| **1단계** | 약하게 움직입니다. |
| **2단계** | 중간 정도로 움직입니다. |
| **3단계** | 가장 크게 움직입니다. 기본값입니다. |

---

## 🧭 Dock에 표시

켜면 Dock에 **Typing Pet 아이콘**이 표시됩니다.

- 메뉴 막대 아이콘은 그대로 유지됩니다.
- Dock 아이콘을 클릭하면 설정 창이 열립니다.
- 기본값은 **꺼짐**입니다.

---

## 🚀 로그인 시 자동 실행

켜면 Mac에 로그인할 때 Typing Pet이 자동으로 실행됩니다.

- 기본값은 **꺼짐**입니다.
- 기능을 끄면 로그인 항목 등록도 해제됩니다.
- `시스템 설정 → 일반 → 로그인 항목 및 확장 프로그램`에서도 직접 끌 수 있습니다.

- 한국어
- English
- 日本語
- 简体中文

`설정 → 일반 → 언어`에서 변경할 수 있으며 선택 즉시 적용됩니다.

## 🔄 업데이트

새 버전이 나오면 Typing Pet이 알려 줍니다. **지금 업데이트**를 누르면 새 버전을 받아 설치하고 다시 실행합니다. 입력 모니터링 권한과 설정은 그대로 유지됩니다.

- 하루에 한 번 자동으로 새 버전을 확인합니다.
- `설정 → 업데이트 → 업데이트 확인` 또는 메뉴 막대 아이콘의 **업데이트 확인…**으로 직접 확인할 수 있습니다.
- `자동으로 업데이트 확인`을 끄면 직접 확인할 때만 접속합니다.
- 이 저장소의 릴리즈에 올라온 파일만 설치합니다. 받은 파일이 원래 앱과 같은 서명이 아니면 설치하지 않습니다.

# 🖼️ 캐릭터 이미지

`설정 → 캐릭터`에서 다음 이미지를 변경할 수 있습니다. 이미지 타일을 누르거나 타일 옆 **⋯** 메뉴에서 바꿀 수 있습니다.

- 기본
- 왼손
- 오른손
- 패턴 이미지

### 지원 형식

| 형식 | 지원 |
|---|:---:|
| PNG | ✅ |
| JPG / JPEG | ✅ |
| GIF | ✅ |
| APNG | ✅ |

투명한 배경이 필요한 경우 **투명 PNG 또는 APNG** 사용을 권장합니다.

### 권장 이미지 크기

**800 × 500 px**

기본 / 왼손 / 오른손 이미지는 동일한 캔버스 크기와 동일한 위치 기준으로 제작하면 가장 자연스럽게 움직입니다.

화면에 표시되는 캐릭터의 크기와 비율은 **기본 이미지**를 기준으로 정해집니다.

`기본값` 버튼을 누르면 원래 이미지로 되돌릴 수 있습니다.

---

# 🎞️ GIF / APNG

움직이는 GIF 및 APNG 이미지를 캐릭터로 사용할 수 있습니다.

패턴 이미지에도 동일하게 사용할 수 있습니다.

키 입력 등에 의해 이미지가 변경될 때마다 애니메이션은 **첫 프레임부터 다시 재생**됩니다.

### 제한

| 항목 | 제한 |
|---|---:|
| 파일 크기 | **15 MB 이하** |
| 프레임 수 | **300 프레임 이하** |

이미지 크기가 크거나 프레임 수가 많을수록 메모리 사용량이 증가할 수 있습니다.

# 🎯 패턴 기능

특정 키나 키 조합에만 반응하는 별도의 이미지를 설정할 수 있습니다.

패턴은 **최대 3개**까지 등록할 수 있습니다.

### 패턴 등록 방법

1. `설정 → 캐릭터`를 엽니다.
2. `+ 패턴 추가`를 누릅니다.
3. `트리거 기록` 버튼을 누릅니다.
4. 원하는 키 또는 키 조합(⌘ ⌥ ⌃ ⇧ 포함)을 누릅니다.
5. `이미지 변경`으로 표시할 이미지를 선택합니다.

프리셋을 저장하면 **트리거와 패턴 이미지도 함께 저장**됩니다.

평소에는 왼손/오른손 이미지가 번갈아 나타나며, 등록된 트리거를 입력한 순간 패턴 이미지가 표시됩니다.

> [!NOTE]
> Typing Pet은 키보드 입력만 감지합니다. 마우스 클릭이나 스크롤에는 반응하지 않습니다.

---

# 💾 프리셋

현재 이미지와 패턴 설정을 **최대 3개**까지 저장할 수 있습니다.

## 저장

1. `설정 → 프리셋`을 엽니다.
2. 프리셋 1~3 중 원하는 슬롯을 선택합니다.
3. 프리셋 이름을 입력합니다.
4. `현재 설정 저장`을 누릅니다.

프리셋 이름은 **최대 16자**까지 사용할 수 있습니다. 이미 저장된 슬롯에 다시 저장하면 덮어쓸 것인지 확인합니다.

## 적용

`적용` 버튼을 누르면 해당 프리셋이 현재 기본 펫에 적용됩니다.

## 수정

저장된 프리셋에서는 각 이미지를 따로 수정할 수 있습니다.

- **이미지 변경** — 선택한 이미지만 변경
- **기본값** — 해당 이미지를 기본 이미지로 초기화
- **삭제**(패턴 옆) — 선택한 패턴 제거
- **이름 변경** — 프리셋 이름 변경
- **삭제**(프리셋) — 프리셋 삭제

프리셋에서 변경한 내용은 우선 **해당 프리셋에만 저장**됩니다. 기본 펫에도 적용하려면 `적용` 버튼을 눌러 주세요.

---

# 🐾 멀티 펫

저장한 프리셋의 캐릭터를 데스크톱에 추가로 띄울 수 있습니다.

프리셋의 **펫 띄우기** 버튼을 누르면 해당 프리셋의 캐릭터가 나타나고, 다시 누르면 사라집니다.

### 동시에 사용할 수 있는 펫

**기본 펫 포함 최대 3마리**

추가한 펫도 기본 펫과 같은 키 입력에 함께 반응하며, 각 펫은 자신이 연결된 프리셋의 이미지와 패턴을 사용합니다.

다음 설정은 기본 펫의 설정을 함께 따릅니다.

- 크기
- 흔들림
- 항상 위에 고정
- 위치 잠금

추가 펫도 마우스로 자유롭게 이동할 수 있으며 위치가 저장되어 다음 실행 시 이전 위치에 다시 나타납니다.

# 🔒 개인정보 보호

Typing Pet은 키보드 입력을 감지하지만 **어떤 글자를 입력했는지는 사용하지 않습니다.**

앱에서 사용하는 것은 단순히:

> **"키가 눌렸다"**

는 사실과, 패턴 기능을 위해 어떤 키가 눌렸는지 비교하는 것뿐입니다.

Typing Pet은 입력한 문자나 문장을:

- 저장하지 않습니다.
- 파일로 기록하지 않습니다.
- 네트워크로 전송하지 않습니다.

Typing Pet이 인터넷에 접속하는 것은 **새 버전 확인과 다운로드**뿐이며, 이때는 이 저장소의 GitHub Releases에만 접속합니다. 키 입력이나 설정은 보내지 않습니다. 자동 확인은 `설정 → 업데이트 → 자동으로 업데이트 확인`에서 끌 수 있습니다.

설정과 사용자가 고른 이미지는 `~/Library/Application Support/TypingPetMac`에 저장됩니다. 앱을 삭제할 때 이 폴더를 함께 지우면 사용자 설정도 삭제됩니다.

# 🔐 SHA-256 파일 검증

GitHub Release에 함께 표시된 SHA-256 값으로 다운로드한 파일의 무결성을 확인할 수 있습니다.

터미널에서 zip 파일이 있는 폴더로 이동한 뒤 다음 명령을 실행하세요.

```bash
shasum -a 256 TypingPetMac.zip
```
